# cshl-meetings

Posters presented by the Galaxy team at Cold Spring Harbor Laboratory (CSHL) meetings.

## Layout

```
<year>/<meeting>/<lastname>/
```

Example: `2026/biological-data-science/nekrutenko/`

## Adding a poster

1. Create `<year>/<meeting>/<lastname>/` and drop in your poster source (`pptx`, `key`, `ai`, `svg`, etc.).
2. Open a PR against `main`.

Source only — PDFs are generated and printed from this repo. Keep files under 50 MB.
